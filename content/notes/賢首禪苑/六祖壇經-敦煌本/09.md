## 1. 本講概要

本講的脈絡有兩層。前半以《楞嚴經》為綱，講「不知兩種根本，盲修瞎練」：第一根本是無始生死，以攀緣心為自性（〔行028〕–〔行037〕）；第二根本是不知菩提涅槃元清淨體，以至「識精元明」生諸緣，「緣所遺者」失此本明，枉入諸趣（〔行170〕–〔行176〕、〔行182〕–〔行184〕）。講者用八識（〔行048〕–〔行099〕）與五法（〔行139〕–〔行149〕）把這兩個根本拆開來說：第六識是「常審」的分別識，第七識是「常恆常審」的我執識，第八識是「常恆非審」的倉庫（〔行085〕–〔行099〕）。

後半轉入敦煌本定慧品，核心是「定慧體一不二」：「即定是慧體，即慧是定用」，「即慧之時定在慧，即定之時慧在定」（〔行331〕）。講者以燈與光為喻（〔行339〕–〔行341〕），以牛頭「恰恰用心時，恰恰無心用」證成日常行住坐臥即是定慧（〔行427〕–〔行446〕）。定慧的「慧」在講者的讀法裡落在「善分別諸法相」（〔行531〕–〔行548〕），「定」落在「於第一義不動」。最後以《文殊師利所說摩訶般若波羅蜜經》的「法界一相，繫緣法界」為一行三昧的理論底（〔行716〕–〔行748〕），收束到「直心是道場」（〔行599〕–〔行607〕）與「行住坐臥，隨流認得性」（〔行647〕–〔行661〕）。

講者在〔行599〕起明言，《壇經》的一行三昧「不是叫我們離開日常生活」，而是「在行住坐臥的當下，知道它全部是影像」（〔行697〕）。

## 4. 故事・公案

**4.1 阿難與兩種根本（《楞嚴》）。** 佛告阿難：眾生修行而不得無上菩提，乃至墮二乘、入魔眷，原因在於「不知兩種根本」。講者說，這一段是《楞嚴》「開悟的楞嚴」的起點（〔行019〕–〔行025〕、〔行143〕）。

**4.2 憨山大師與冰（《楞嚴》直解）。** 憨山在五台山，冬去春來，冰開始融化，他於冰融之時大徹大悟；講者說他悟的是「冰有水性」，即「性覺必明」之理（〔行187〕–〔行197〕）。講者說此事並非偶然，「不是你修來的，是本有的」（〔行520〕）。講者又引憨山的話「煩惱性即是菩提性」（〔行197〕），此句見 §9 ※（M6）。

**4.3 六祖與神秀的偈（曹溪本）。** 神秀「時時勤拂拭，勿使惹塵埃」，六祖「本來無一物，何處惹塵埃」。講者說：神秀還有能所，「要把第七意識磨掉」，六祖則「本來沒有這樣東西」（〔行113〕–〔行117〕、〔行609〕–〔行615〕）。

**4.4 梁武帝與達磨（《景德傳燈錄》等）。** 梁武帝自以為造寺、供僧功德大，達磨說「無功德」，二人「語言不通」，達磨北去（〔行260〕–〔行270〕）。講者說這個「功德」是攀緣心所立的標籤，「罪福是現象界的東西，是虛幻相」（〔行260〕）。

**4.5 永嘉玄覺一宿覺。** 永嘉至曹溪，六祖只留一宿，他即得證道歌（〔行395〕–〔行398〕）。講者說證道歌有人說不是永嘉所作，但「學佛不理會這個」，依永嘉全集（〔行398〕–〔行400〕）。

**4.6 懶融與四祖。** 四祖道信稱讚懶融，懶融說「恰恰用心時，恰恰無心用」（〔行427〕–〔行436〕）；講者以此為定慧一體的三個例子之一（〔行444〕）。

**4.7 陳惠明與「不思善不思惡」。** 六祖與陳惠明「不思善，不思惡，正與麼時」，講者說此即「明上座的本來面目」；他要大家在「能生氣的是誰」處參（〔行453〕–〔行462〕）。

**4.8 法海問即心即佛（《景德傳燈錄》）。** 法海問即心即佛何意；六祖答「前念不生，謂之心；後念不滅，謂之佛」；法海「跪著頂禮」。講者說此段「沒有解釋的話這是什麼意思」，並自解為「念念全部空寂，不受念的干擾」（〔行469〕–〔行516〕）。

**4.9 維摩默然。** 文殊說「於一切法無言無說，無示無識，是為入不二法門」，眾人說完，維摩默然，眾人頂禮（〔行343〕–〔行349〕）。講者說「你們講那一大堆都是定出假議題」（〔行349〕）。

**4.10 臥輪與玄奘「心流住」。** 臥輪「有伎倆，能斷百思想」，六祖說「無伎倆，不斷百思想」。講者說玄奘譯《金剛經》為「心流住」，「心流住」是把心圍堵；以大禹治水（不是堵，是疏導）作譬（〔行359〕–〔行365〕）。講者的玄奘譯本之說見 §9 ※ 與 §12。

**4.11 燃臂供佛。** 講者自述少時燃臂供佛、燃胸，留下戒疤（〔行371〕–〔行373〕）。講者的用意是：「用火把自己燒個卍字」是「自己製造麻煩來麻煩自己」（〔行373〕）。

**4.12 陳惠明、達磨、萬益。** 萬益大師「法海觀瀾」：戒→教→禪淨密，「禪淨密三則一，一則三」（〔行573〕–〔行591〕）。

**4.13 神秀與五祖傳法。** 講者說五祖若以神秀有能所，「不可能把禪的法脈傳給他」（〔行609〕–〔行615〕）。

**4.14 懶融與「一行三昧」。** 見 4.6。

**4.15 楞伽師資記。** 師資記的次第：第一位求那跋陀羅，第二位菩提達磨；四祖、五祖無記載，惠能亦無記載，神秀列為最後一位（〔行702〕–〔行704〕）。講者說四祖五祖稱為黃梅法門，以《楞伽》與《文殊》一行三昧為法（〔行702〕–〔行714〕）。

**義理深入。** 講者把「定慧一體」讀為「本來現成」：「定慧是眾生本具，不是你修來的」（〔行520〕–〔行523〕）。定慧之所以不二，是因為「能所不二」「本來是不二」，而眾生「自己製造能所的二，再欺負自己」（〔行249〕、〔行325〕、〔行551〕–〔行553〕）。

**一行三昧的脈絡。** 六祖的一行三昧，講者認為是「定慧等持的一行三昧」，而非《起信論》的「三無差別」或《文殊》的「繫緣一相」（〔行554〕–〔行556〕）。此處講者引《淨名經》「直心是道場，直心是淨土」（〔行597〕–〔行599〕），並說「直心是當下就是的那顆心」（〔行607〕）。

## 10. 法脈會通

**（一）第一、第二根本與八識的對應。**

```
  兩種根本（楞嚴〔行143〕）
  ├── 第一根本：無始生死 ─ 以攀緣心為自性 ─ 第七意識 manas（我執）
  └── 第二根本：不知元清淨體 ─ 識精元明 ─ 遺失本明 ─ 枉入諸趣
```

```
  八識 → 五法 → 結果
  第一～五識   非恆非審  ─ 只負責反應
  第六識       非恆常審  ─ 分別識；佛為妙觀察智，凡夫為分別智
  第七識       常恆常審  ─ 我執識（相：我相人相眾生相壽者相）
  第八識       常恆非審  ─ 倉庫（不判斷，都接受）
```

**（二）性覺必明 → 無明 → 十二因緣。**

```
  本來就明（性覺必明）
     └─▶ 妄為明覺（找明）
           └─▶ 因明立所（立能所）
                 └─▶ 生汝妄能（有能有所）
                       └─▶ 相待生勞（能所相衝，內心煩惱）
                             └─▶ 一念不覺生三細 → 地水火風 → 山河大地
```

（講者的鏈，〔行225〕–〔行233〕。「風波動就風，風跟地摩擦產生火，火又生水」為講者之述，未另核。）

**（三）五方五佛的對應。** 「地水火風在波動的現象裡面，對內是相待成勞，對外就是山河大地的由來」（〔行249〕）。

**（四）定慧、惺惺寂寂、恰恰用心的三證。** 講者以三個例子互證「定慧不二」：懶融「恰恰用心時」（〔行427〕–〔行436〕）、永嘉「惺惺寂寂」（〔行400〕–〔行421〕）、《金剛經》「應無所住而生其心」（〔行355〕–〔行357〕），並說「從三個印證《金剛經》」（〔行444〕）。

**（五）黃梅法門。** 師資記：「四祖五祖稱黃梅法門，以《楞伽》為即心即佛，以《文殊》一行三昧為一行三昧」（〔行704〕–〔行716〕）。

**（六）與前講的連接。** 第八講末已講「定惠等」，本講接續（〔行329〕、〔行335〕、〔行351〕）。

## 11. 日常實踐

- **行住坐臥，常行直心。** 「行住坐臥」並非離開；隨流認得性，知一切為影像而不執（〔行697〕、〔行758〕–〔行764〕）。
- **生氣之前，一秒鐘問自己：能生氣的是誰？** 講者說此即「明上座的本來面目」，是參話頭之法（〔行454〕–〔行460〕）。
- **外息諸緣，內心無喘。** 達磨所說；六根接觸六塵，不被干擾（〔行564〕–〔行572〕）。
- **念佛要念實相。** 「念出聲音是緣起，緣起的當下回歸性空」；不求外在功德（〔行675〕–〔行685〕）。
- **不以為「身在修行」而忽略本具。** 「不要貪看外面的明月而忽略手中的寶珠」（〔行685〕）。
- **恰恰用心，恰恰無心。** 日常做事，既用心，又不起執（〔行436〕–〔行446〕）。

- 「狂心不歇，歇即菩提」之出處：講者說出自《楞嚴》及憨山（〔行107〕、〔行209〕、〔行522〕）；T0945 本文未見，見於 T1791、T1799 注疏。
- 「前念不生謂之心，後念不滅謂之佛」「即心成慧，即佛乃定」：講者說出自《景德傳燈錄》法海問（〔行469〕–〔行516〕）；本庫 CBETA 未找到逐字。
- 「心不自心，因境故心」歸於「二十二祖」（〔行647〕–〔行649〕）；本庫所見為 T1848 華嚴疏。
- 「一行三昧，三無差別」（《起信論》，〔行555〕）；本庫未逐字核。
- 「玄奘譯《金剛經》為心流住」（〔行359〕–〔行361〕）：見 M2。
- 憨山「煩惱性即是菩提性」（〔行197〕）：見 M6。
- 寶誌〈大乘讚〉「道俗崢嶸」、陳惠明「不思善不思惡」：本庫未逐字核（〔行097〕–〔行101〕）。

**12.2 版本。** 本講以敦煌本為綱，但講者多引曹溪本（T2008）之句（如「何期自性」「本來無一物」「時時勤拂拭」）。本庫以 T2007 為本經；T2008 之句標註為版本差異，不以之取代敦煌本。
