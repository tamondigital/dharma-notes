## 1. 本講概要

本講是《金剛經》系列第六講。體佛法師先以「安住／降伏」兩問總攝前五講，指出《金剛經》為最上乘之經、一切諸佛阿耨多羅三藐三菩提都從此經出〔行87–91〕〔行167–169〕，再沿經文次第往下講解四個段落〔行165–167〕：

- **第五 如理實見分**——「凡所有相，皆是虛妄；若見諸相非相，則見如來」（法師誦作「皆是虛幻」），以六根六塵六識（十二處、十八界）說明「一切相都是自心影像」〔行115–119〕〔行117–123〕。
- **第六 正信希有分**——「後五百歲有持戒修福者」能生信心，帶出「三取（取相／取法相／取非法相）→ 三空（我空／法空／空空）」的修證核心〔行179–181〕〔行209–211〕。
- **第七 無得無說分**——「無有定法名阿耨多羅三藐三菩提」「一切賢聖皆以無為法而有差別」，以彌勒偈「應化非真佛，亦非說法者」與佛三身（法報化）解「說而無說」〔行229–234〕〔行260〕〔行265–278〕〔行440〕。
- **第八 依法出生分**——三千大千世界七寶布施「即非福德性」，不如受持四句偈；帶出財施／無畏施／法施之辨與「所謂佛法者，即非佛法」〔行449–453〕〔行573–575〕。

貫串全講的一條主線是體佛法師反覆強調的：**真心眾生本具、本來安住**，痛苦只因「妄心住相」；《金剛經》不是教你「修」而是教你「觀」——觀一切相皆自心所現之虛幻影像，於相不取著（受持）即回歸自性〔行89–93〕〔行111–113〕〔行622–624〕。

## 2. 大綱（含〔行〕）

1. **總攝前五講**：如來性德、須菩提代眾生發問、安住／降伏兩問〔行81〕–〔行91–95〕
2. **大乘正宗回顧**：滅度無量眾生而實無眾生得滅度、彌勒偈四句〔行93–97〕–〔行95–97〕
3. **四相**：我相為主，我相一出四相具足，除任一相三相俱除；真心本無四相，妄心有我故有四相〔行97〕–〔行99–101〕
4. **妙行無住**：無住相布施、東方虛空喻福德、菩薩但應如所教住、住相即苦〔行101–103〕–〔行115–117〕
5. **如理實見分**：凡所有相皆虛妄、六根六塵六識、一切有為法如夢幻泡影〔行115–119〕–〔行129–131〕
6. **六祖口訣**：佛性雖堅如般若、煩惱可障、般若可破〔行125–129〕〔行578〕
7. **正信希有分**：後五百歲持戒修福、修福即布施、閻羅生死簿=自心因果〔行129–133〕–〔行163–167〕
8. **昭明太子補充**：蕭統分三十二分、佛經不可裁、四大菩薩八大金剛護持〔行165–167〕–〔行179〕
9. **三取→三空**：心是根法是塵鏡上痕、黃蘗心外無法、斷滅相、身我／主宰我〔行179–181〕–〔行219–223〕
10. **無得無說分**：無有定法、皆不可取不可說非法非非法、一切賢聖皆以無為法而有差別〔行221–223〕–〔行236–238〕〔行353〕–〔行442〕
11. **彌勒偈解「說而無說」**：應化非真佛、佛三身法報化、般若無知〔行248–250〕–〔行343–345〕
12. **依法出生分**：福德即非福德性、三施之辨、金剛心論偈、四大菩薩會通、皆從此經出、心經、般若佛母〔行445〕–〔行579〕
13. **所謂佛法者即非佛法**：不見一法即如來、圓覺知幻即離、黃蓋苦肉計、證道歌結頌〔行573–575〕–〔行662–664〕

## 4. 故事・公案（全敘事）

### 4.1 諾貝爾獎得主與「宇宙法則」（開場因緣）〔行83–87〕
法師開講時回顧第五講末提到的一位諾貝爾獎得主：他是罕見能講靈魂論而得到正式諾貝爾獎的科學家，說地球是三度（三維）空間，多維次空間的高層次者一致發願到地球來告訴眾生真相；問其為何如此，他說這是「宇宙法則」。法師藉此點出：悟道過程中或已悟道者，自然很想與眾生分享，自己也不知為什麼——這就叫「如來善護念諸菩薩、善付囑諸菩薩」，是眾生本具的性德〔行83–89〕。

### 4.2 昭明太子蕭統分經三十二分〔行165–167〕–〔行173–177〕
講到「正信希有」分名時，法師補充：昭明太子名**蕭統**，是**梁武帝**最鍾愛、最想重用的兒子，於文學、佛法、軍事、藝術各方面皆有傑出表現、智慧甚高，惜早逝。因他編了**《昭明文選》**（國中、高中、大學課本常見），故世稱昭明太子。他深知《金剛經》極重要（「一切諸佛阿耨多羅三藐三菩提皆從此經出」），為勸母親讀誦，特將《金剛經》分成三十二分。法師隨即提出警語：昭明太子用心雖好，**但佛經不能隨便分段、不能增減原文**；作註疏、作總結可以，裁剪編排經文不行。故念《金剛經》時應念鳩摩羅什所譯全文一路念到底，看「分」只是研究時作疏之用。（史實：蕭統為梁武帝長子，編《文選》，三十二分則傳為其所判——與法師所述相符。）

### 4.3 圓覺經賢善首菩薩·火首金剛護持〔行175–179〕–〔行177–179〕
法師以《圓覺經》最後一品（賢善首菩薩章）為例：有人受持讀誦《圓覺經》時，諸大明王一一來護持，第一位即「火首金剛」，率領諸天護法乃至鬼神都來護持。藉此說明念《金剛經》時「四大菩薩、八大金剛」的無形護持之力不可否認——你的金剛心（能量）現前時，會招感護持此經的大菩薩、大金剛，因祂們都有護法之願。

### 4.4 黃蘗禪師三掌唐宣宗（著空公案）〔行532–534〕–〔行536–538〕
法師先理禪宗血脈：黃蘗禪師的師父是**百丈禪師**，百丈的師父是**馬祖道一**，馬祖的師父是**懷讓禪師**，懷讓的師父是**六祖惠能**，一脈相傳。黃蘗《傳心法要》專門講「空」。故事：唐宣宗（俗名**李忱**）尚未登基時，見黃蘗禪師拜佛像，便問：「既然一切是空，為什麼你還要拜佛像？」黃蘗當下給他三巴掌——喝斥他「著空」。法師以此說明學佛最易偏入兩邊：不是著相就是著空，二者皆非中道。

### 4.5 三國演義·黃蓋苦肉計（願打願挨）〔行590–592〕–〔行599–601〕
為說明「六根接觸六塵之痛只是覺受、可被心轉」，法師舉《三國演義》黃蓋苦肉計：一個願打、一個願挨。黃蓋被周瑜打得皮肉裂開卻「很爽快、很高興」，因為他知道只要曹操相信這場「叛變」，就能以火攻破連環戰船。他忍痛去詐降曹操，訴說被周瑜毒打、心懷怨恨要叛變；又獻計要曹操把船連鎖成平地以免北軍暈船——曹操信以為真，中周瑜、孔明之計。法師結論：痛是覺受，心作用轉之，痛也可以痛得爽快；同理大病臨身，心若不被病折磨，人便不受其苦。

### 義理深入

**如理實見分——「見諸相非相」是全經的觀門。** 體佛法師把此分定位為佛給須菩提的「一帖良藥」：前面說了無住相布施、四相俱除，這裡直接開出「怎麼做到」——不是去修，而是「觀」。一切相（山河大千）都是六根接觸六塵、經六識所現的塵相影像；你看到相就是看到鏡子（心），若能於相見其「非相」（知其為影像），本具的如來當下即現〔行115–119〕〔行129–131〕。法師特別強調：佛「沒有叫你怎麼修，叫你怎麼觀」——這是本講對《金剛經》最核心的定調〔行125–129〕。

**正信希有分——三取三空是本講的修證骨架。** 法師把此分讀成一套「離取」的次第：眾生的病只有一個「我」在作主宰（身體我＋主宰我），由我相生法相、由法相怕落空而生「非法相（空相）」；對治即「三取一破，進入三空」——我空（我是假、非無我）、法空（法是假、非無法）、空空（連空也要空，免落斷滅）〔行209–211〕〔行217–221〕。他反覆提醒「空是假名不是斷無」，避免把《金剛經》讀成頑空〔行205–207〕。

**無得無說分——以彌勒偈與佛三身解「說而無說」。** 此分是本講義理最密之處。須菩提「意猶未盡」：既然是三空，什麼都空，連佛也空、連取得菩提也空、連說法也空，那怎麼成佛？〔行223–225〕佛遂反問兩句。法師引彌勒偈「應化非真佛，亦非說法者，說法不二取，無說離言相」（✓CBETA T1511；字幕 OCR 於「應化非真佛」後多一雜字「办」）〔行260〕與佛三身（法報化）作答：問二千五百多年前在尼泊爾誕生的釋迦牟尼佛是什麼身〔行271〕；法身是清淨佛毘盧遮那，千百億化身是釋迦牟尼佛，故「報化非真佛」——不是清淨法身佛〔行274–278〕；祂講的不是真說，是「因緣而說」，根據眾生不同習性講他可以受用的，「因緣說就是生滅說」；法身的觀點是「無說」——法性空寂〔行284–292〕。因此讀經要分辨：擷取片段，有時是報化身佛對不同根器眾生的當下之說，「只要一乘法的經最後法身佛都會出來 圓滿收尾」——不能片段看〔行298–300〕。「一切賢聖皆以無為法而有差別」正是收在無為法：雙非的非法、非非法，總歸一句話就是無為法，本自清淨、眾生本具〔行440–442〕。

**依法出生分——福德性與三施之辨導向「般若佛母」。** 法師用證道歌「住相布施生天福，猶如仰箭射虛空」印證「福德相≠福德性」〔行457–461〕，再把布施分財施／無畏施／法施，指出唯法施「具足二莊嚴（福慧）」、能助眾生了生死到彼岸〔行491–493〕。最後匯歸「一切諸佛及諸佛阿耨多羅三藐三菩提法，皆從此經出」——《心經》結歸「以無所得故」是《金剛經》的總合，故般若稱「佛母」；而這一切「非從外來，是眾生本具」〔行564–566〕〔行571–573〕。「所謂佛法者，即非佛法」則以「所謂＝假設語氣」「手指指月」作結：佛與法唯為對治眾生「自認是眾生」而不得不立，究竟則「以佛性而言，哪有佛」〔行626–628〕〔行646–648〕。

| 觀音 | 大悲 | 滅度無量眾生令入無餘涅槃 | 金剛經=觀音法門 | 〔行548〕 |
| 勢至 | 大智 | 實無眾生得滅度者 | 觀音+勢至=阿彌陀→金剛經亦淨土法門 | 〔行550〕 |
| 維摩（淨名） | 性相不二 | 淨=性、名=相，入不二法門 | 空有不二＝金剛經＝維摩詰經翻版 | T0475 ✓ |

連結要點：黃蘗云「文殊當理、普賢當行、觀音大悲、勢至大智、維摩淨名，皆在一心」——這些皆眾生本具，故「心即是觀音、普賢、文殊、勢至、淨名」〔行560–562〕；淨土「我心即彌陀，彌陀即我心」同理〔行560–562〕。

### 10.4 有為法 ↔ 無為法 等值鏈（證道歌貫穿）〔行402〕〔行422〕

```
  有為法 = 妄心所現 = 生滅 = 住相布施(生天福) = 仰箭射虛空(勢盡箭墜) = 福德相 = 此岸
      │  對治：三取一破 → 三空 / 覺即了不施功 / 知妄即離
      ▼
  無為法 = 眾生本具 = 無生滅 = 清淨 = 無能無所 = 一超直入如來地 = 福德性 = 彼岸
                                  = 賢聖所入(深淺不同→差別) = 大海(非海中漚)
```
連結要點：「爭似無為實相門」的「皈依」即回歸本有的無為實相；入無為法方名賢聖，同入而有深淺（三獸渡河）〔行432–434〕〔行434–436〕。

## 11. 日常實踐（可操作）

1. **念《金剛經》念全文**：從鳩摩羅什譯本頭念到尾，不要「念幾分幾分」；看三十二分只作研究時的科判〔行177–179〕〔行171–175〕。
2. **受持＝不取著**：不是求念經遍數的功德，而是念時「不執著、無所住而生其心」；有一分著相就一分不是受持〔行511–513〕〔行660–662〕。
3. **觀而非修**：對一切境相（乃至自己身心）作「這是自心所現影像」之觀（凡所有相皆虛妄），不被虛幻相干擾——「不是它折磨我，是我要不要被它折磨」〔行601–603〕〔行620–622〕。
4. **柔軟語·菩薩四德**：勿以「我直心」為藉口傷人；直心是道場不等於直來直往；菩薩德「柔和質直」，柔軟語安慰眾生〔行153–155〕〔行153–157〕。
5. **當下懺悔起心動念**：閻羅生死簿即自心因果念頭；起了傲慢、是非、惡念要當下懺悔——「了則業障本來空」〔行139–143〕〔行603–605〕。
6. **重法施、亦不廢財施**：法施具足福慧二莊嚴、能助人了生死；財施是資生、亦有福但非成佛因；相莊嚴（道場）用以引發性莊嚴，不著相亦不廢相〔行489–491〕〔行526–528〕。
7. **依義不依語，勿以文字批判人**：文字般若是為起觀照回歸實相，不要在文字上作文章、批判他人——「批判別人就是批判自己」〔行648–650〕〔行652–654〕。

## 12. 延伸・參

### 校勘・待考

- **※「金剛心論·文殊菩薩」的偈頌歸屬**〔行480–480〕〔行483–485〕：法師稱「法施具足二莊嚴，財是非因故非勝，應知法施離取著，取著不名為受持」出自《金剛心論》、是「文殊菩薩開口來講的」。經全 CBETA 語料檢索，此四句偈**僅見於明·智旭（蕅益大師）《金剛經破空論》X0479**（作「財施非因故非勝」），本語料庫**無**含此偈之「金剛心論」。傳世另有疑偽經《金剛心總持論》（文殊師利問佛體例），惟不在本庫、且未見此偈。**保留法師原話，並註明可核驗之出處為 X0479 智旭《破空論》**。
- **※「三獸渡河」出處**〔行434–436〕：法師稱「《法華經》裡面經典講三獸渡河」。經核，兔·馬·象「三獸渡河（渡十二因緣河，深淺喻證境）」出自**《大般涅槃經》T0374**（「未能渡十二因緣河，猶如兔馬」）與**《優婆塞戒經》T1488**；《法華經》T0262 無此喻（《法華》為「三車：羊鹿牛」）。**保留法師原話，補正 canon 出處為涅槃經／優婆塞戒經。**
- **※證道歌·圓覺經誦文字異（保留法師原誦，附 canon）**：
  - 「招來來生不如意」→ T2014「招得來生不如意」〔行389–391〕
  - 「此則名為觀自在」→ T2014「方得名為觀自在」〔行605–607〕
  - 「了則業障本來空，不了還需還宿債」→ T2014「了即業障本來空，未了應須還夙債」〔行605–607〕
  - 「一切賢聖如電拂」→ T2014「一切聖賢如電拂」〔行640–644〕
  - 「知幻即離，知離即覺」→ T0842「知幻即離，不作方便；離幻即覺，亦無漸次」〔行586–588〕
  - 「兩者猶如鏡上痕」→ T2014「兩種猶如鏡上痕」〔行189–191〕
  - 「狂心不歇，歇即菩提」→ T0945「狂性自歇，歇即菩提」〔行410–412〕
  （以上皆屬口誦異文，義理不變，攝屬正確。）
- **屬實·非誤**：黃蘗禪師血脈（六祖→懷讓→馬祖道一→百丈→黃蘗）〔行532–534〕、昭明太子（蕭統／梁武帝子／昭明文選／三十二分）〔行165–167〕、鳩摩羅什譯《金剛經》於後秦（法師稱「魏晉南北朝時代…格義」，時代大範圍屬實）〔行387〕——均與史實相符。

### 一參問

法師說「佛沒有叫你怎麼修，叫你怎麼觀」〔行125–129〕。那麼——當你此刻正被一個「討厭的人的影像」折磨時，你能不能不去「忍耐」（愈忍愈折磨）、也不去「消滅」它，只是看它是「自心所現的一個法相」而不取著？這一念之間，就是《金剛經》「若見諸相非相，則見如來」的當下試驗。
