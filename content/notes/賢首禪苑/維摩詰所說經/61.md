## 1. 本講概要

第61講是《維摩詰所說經》的尾聲：**正宗分（第一〈佛國品〉至第十二〈見阿閦佛品〉）已結束，本講進入流通分**，流通分共兩品，本講開〈法供養品〉〔行11〕〔行14〕。

全講分兩大半：

1. **前半（約〔行14–280〕）——全經通盤複習。** 體佛法師要大眾「把這部經的全文整個的涵義通盤了解」：此經「不但是了生死的經，是成佛的經，而且是度化眾生的經」〔行16〕。他逐品串講十二品的編排用意（佛國→方便→弟子→菩薩→問疾→不思議→觀眾生→佛道→不二→香積→菩薩行→見阿閦佛），並把整部經收攝為一句：**「從第一品開始，維摩詰跟佛陀無非要讓我們認識：我們有一個永恆不變的本心，這本心的如來性是所有眾生共用的，稱為如來藏」**〔行152–156〕。第一品〈佛國品〉與正宗分末品〈見阿閦佛品〉首尾呼應，都在講「不變的本心」〔行158〕。其間穿插：緣起緣滅合稱「眾生」〔行38–42〕、「不執著」三字訣〔行56〕、一切法從心想生〔行62–76〕、煩惱即菩提〔行100–104〕、嗔本無生〔行128–136〕、真空妙有與聖凡之別〔行162–176〕、以幻取幻（三摩鉢提）〔行210–214〕、三昧耶戒四戒體〔行242–264〕。
2. **後半（約〔行282–957〕）——〈法供養品〉經文與開顯。** 天帝（釋提桓因＝玉皇上帝）作證「未曾聞此決定實相經典」〔行284〕〔行309–323〕；師以《永嘉證道歌》「決定說」〔行325–333〕、實相三相貌（無相·無不相·無相無不相＝空·不空·空不空如來藏）〔行337–341〕、三乘布施之別〔行341–377〕，再以**《道德經》第五章（師稱「卷五·用中」）**為本講最大開展〔行394–507〕，接著以**《楞嚴經》「性色真空、性空真色……循業發現」**補足第60講〔行509–608〕；回經文講持經功德、破四魔〔行610–652〕、天帝護法願〔行660–680〕、佛讚與校量功德〔行680–801〕，最後讀到藥王如來本事與「法供養者，諸佛所說深經」〔行803–839〕，並以如來藏「空／不空／空不空」逐句開解法供養〔行879–953〕。

**全講主軸（through-line）：** 《維摩詰經》是「決定實相」之經——決定＝直截根源、毫無商量，實相＝空不空如來藏。**法供養之所以勝過一切財物供養，是因為「諸佛菩提皆從是生」——法供養令眾生回歸那顆本自具足、不生不滅、所有眾生共用的本心；以空如來藏行不空如來藏，就是成就六度、順菩提法、坐道場轉法輪。**〔行323〕〔行769–801〕〔行909–953〕

本講後半至〔行839〕讀到「十方三世諸佛所說」即說「好先到這邊」；「若聞如是等經……是名法之供養」以下經文本講未讀，師預告下週完整講〔行841–843〕。

## 3. 核心概念（名相釋義＋經教連結）

| 名相 | 體佛法師釋義〔行〕 | 經教連結（核驗見§9） |
|---|---|---|
| **流通分** | 正宗分十二品已結束，流通分有兩品；本講〈法供養品〉讓人知道法供養的重要。〔行14〕 | 《維摩詰經》T0475〈法供養品第十三〉 |
| **眾生（緣生緣滅之合稱）** | 「緣生緣滅，合稱兩個字稱為叫眾生」；有形無形都是眾生，茶杯也是眾生——因緣生，有一天因緣滅就壞。〔行38–42〕 | 師之字義解；見緣起即見法，《中阿含》T0026 |
| **不執著（非放下）** | 佛法「其實只有三個字：不執著而已，不是放下」；在相中不執著，即隨流認得性。動不動就生氣、不滿、抱怨，就是著相、離佛甚遠。〔行56–58〕 | 《金剛經》T0235「若見諸相非相」；二十二祖偈 T2076 |
| **一切法從心想生** | 你想一個人、想一顆鑽石，都是從你心出來的，都是虛幻；從假的裡面產生的情緒（喜歡、討厭）怎麼會是真的。這個「想」叫法塵。〔行62–74〕 | 《證道歌》「心是根，法是塵」T2014 |
| **影射** | 所有眾生都是心顯現、影射出來的幻相；影子射出來的東西不是真的，可我們的煩惱正是在心影射出來的東西上產生。〔行82–84〕 | 師之字義解 |
| **世界與法界不二** | 緣起緣滅、有生滅者叫世界；六根所見變成心中影像，叫入法界。鏡子裡的影像是世界，變成影像又成為你的法界——世界是我心顯現的法界。〔行90–96〕 | 《華嚴經》「應觀法界性，一切唯心造」T0279 |
| **煩惱即菩提** | 煩惱是心煩惱的，心稱為菩提，所以煩惱性就是菩提性；貪嗔痴的本質、六度萬行的實性，都是菩提性。〔行100–104〕 | 〈不二法門品〉義；《證道歌》「無明實性即佛性」T2014 |
| **修是修習性** | 佛性本具足，如無瑕摩尼寶珠，越修越不完整；要修的是對佛性不圓滿的妄念、妄心，即「習性」——我不聽佛講的話，就叫習性。〔行106–110〕 | 《證道歌》「絕學無為閒道人」T2014 |
| **嗔本無生** | 嗔不是忍耐、不是壓抑可克服；嗔本來無生、本來是假的，如空谷響、旋火輪、水中月、鏡中花、乾闥婆（海市蜃樓）、陽焰、芭蕉，無實體；因緣所生當下嗔，就能因緣所生當下滅。〔行126–136〕 | 《楞嚴經》「當處出生，隨處滅盡」T0945 |
| **阿閦（不動）＝本心** | 妙喜國阿閦如來，貪嗔痴不動，故稱不動佛；不動就是我們的本心。妄心是扭曲本心產生的；除去妄心很簡單，除去本心不可能。〔行144–148〕 | 〈見阿閦佛品〉T0475 |
| **本覺本有，不覺本無** | 馬鳴菩薩所說，「給我們最大的鼓勵」：本覺本有，不會失去；不覺本無，本無的東西要讓它沒有才簡單。〔行148〕 | 師歸於馬鳴（《起信論》義），非逐字經文 |
| **如來藏（眾生共用的本心）** | 永恆不變的本心，其如來性為所有眾生共用；我們隨著不同因緣產生不同個體，但都回歸一個不變的本心。〔行152–156〕 | 《楞嚴經》如來藏 T0945 |
| **不變隨緣·真空妙有** | 森羅萬象是不變本心隨緣幻化的幻有；不變又可稱「真空」（本自具足、本自清淨、本不動搖＝阿閦佛），真空碰到緣就生妙有。凡夫以妙有為真有，聖人知妙有是假有——聖凡只差這一點。〔行160–176〕 | 《六祖壇經》「何期自性」T2008 |
| **知道與修行** | 修行第一要「先知道」，第二是在幻有之中體會你真的知道還是不知道；修行無撇步。理論知道叫文殊，行動知道叫普賢，文殊普賢當下叫毘盧遮那。〔行178–186〕 | 華嚴三聖義（師述） |
| **福報 vs 功德** | 凡是相上的都是福報，與功德無關；功德是你心本具的那一個。〔行186〕 | 師之判別 |
| **以幻取幻·三摩鉢提·如幻三昧** | 二元的東西都是緣起緣滅的假；用假的來對付假的、回歸本心：念阿彌陀佛（假）去除假的幻心，回歸真心——以假修真，即《圓覺經》第二法三摩鉢提，也叫如幻三昧；持咒、聽經亦如是。〔行208–214〕 | 《圓覺經》三摩鉢提 T0842 |
| **法界神通** | 相上的神通全是假、是魔術師的幻化；心的不生不滅是唯一的不可思議，法界神通由此而生。〔行216–220〕 | 《幻士仁賢經》T0324（師述） |
| **三昧耶戒四戒體** | Samaya＝我的本心本自清淨本不動；受此即受「無為的心戒」，非有為戒。平等戒、本誓戒、除障戒、警覺戒。〔行242–264〕 | 師之開示（詳§10.4） |
| **賢聖** | 《金剛經》定義：以無為法為基礎而有差別才叫賢聖；在有為法中只能講好人壞人，都不出六道。〔行266–268〕 | 《金剛經》T0235 |
| **決定（決定說）** | 毫無商量；《證道歌》「決定說表真乘」：真乘＝最上乘；有人不肯任情徵（業障深、福報不夠，聽不下去且誹謗）；摘葉尋枝是方便；直截根源佛所印——所印的就是我們的心。〔行323–333〕 | 《永嘉證道歌》T2014 |
| **實相（三相貌）** | 無相·無不相·無相無不相；依《楞伽》如來藏角度＝空如來藏·不空如來藏·空不空如來藏。修行次第可先從空入，再入不空的假，再體悟空不空一體。〔行337–341〕 | 如來藏三分（師述） |
| **三種布施** | 凡夫（人天乘）布施在「有」，求回饋，福報被名字與讚賞領走；聲聞不布施，自利、回歸空性；菩薩空假中合一、三輪體空，空不空。〔行341–369〕 | 《金剛經》滅度無量眾生而實無眾生得滅度 T0235 |
| **天地不仁** | 仁＝「二」，人具陰陽、善惡、佛魔二性；天地不仁＝天地不理會、不干預世間一切事（不介入因果）。〔行409–417〕 | 《道德經》第五章（非佛典，見§6） |
| **芻狗** | 古代以稻草編成狗、豬之形祭祀；祭前珍惜，祭後丟棄。萬物緣起時珍貴，緣滅即棄。〔行429–437〕 | 《道德經》第五章 |

## 4. 故事・公案（全敘事）

### 4.1 月蓋王子問「何謂法供養」（藥王如來本事）〔行847–879〕

**設定：** 佛告天帝：過去無量阿僧祇劫，有佛號藥王如來（十號具足），世界名大莊嚴，劫名莊嚴，佛壽二十小劫；聲聞僧三十六億那由他，菩薩僧十二億〔行847–867〕。體佛法師說明：莊嚴劫在現在的賢劫之前；莊嚴劫最後三尊佛加上賢劫四尊（釋迦牟尼佛是第四尊）合稱七佛，「七佛滅罪真言」即此〔行859–865〕。「佛壽二十小劫」不是講佛身的壽命——佛沒有壽命——是佛跟眾生因緣的壽命〔行865〕。

**發展：** 當時有轉輪聖王名寶蓋，七寶具足，主四天下（四大天王底下的東西南北四部洲），有千子端正勇健、能伏怨敵〔行867–869〕。寶蓋與眷屬供養藥王如來，安頓如來所需的一切，滿五劫；五劫後告訴千子「你們要像我一樣，以深心供養這位如來」，千子受命，也供養滿五劫〔行869–873〕。其中一子名月蓋，獨坐思惟：「寧有供養殊過此者？」——有沒有一種供養超過我們現在的供養？〔行873〕這個意念一發出（「這個波出去了」），佛以神力，空中有天應他：「善男子！有一個可以超過你現在的供養，就是法的供養。」月蓋問什麼叫法供養，天說：「你可以去問藥王如來。」〔行875–877〕月蓋王子便到藥王如來處，稽首佛足、卻住一面——禮佛足以後不敢正面對著佛，就往旁邊一站——白佛：「諸供養中我也知道法供養最勝，那什麼叫法供養？」〔行877–879〕

**要點：** 佛答「法供養者，諸佛所說深經……」。體佛法師以這段經文為全講收束：十劫的財物供養尚不及法供養，因為法供養是令眾生回歸本心（空如來藏），再由本心隨緣度眾（不空如來藏）〔行879–953〕。師結論：「此人即是法供養之最上……沒有比這個供養更加地殊勝，稱為叫做法供養最勝」〔行951–953〕。
- 出處：《維摩詰所說經》T0475〈法供養品〉✓（經文全段見§8）。

### 4.2 老子《道德經》第五章——「天地不仁」破迷信〔行379–507〕

**設定：** 體佛法師提醒：天帝（玉皇上帝）出來了，那「到底玉皇上帝有沒有看到我做事？會不會幫助我、憐憫我？」要看天的想法〔行379–381〕。他說佛教還沒傳入中國時，絕對不能忽略道家；若心中佛與道還有高低，就不解如來真實義〔行381–383〕。「道」就是自性功德：「首」是第一、最上乘，加「走」是不能離開人群——菩薩行於非道，在眾生中與眾生和處〔行383–385〕。中國第一個把道講清楚的是老子；沒有他，佛教傳進中國大乘不會興盛〔行385–387〕。「你安知老子不是古佛再來、不是文殊師利的示現？」〔行389〕老子只留下一部《道德經》：「道者空也，德者不空也」，所以《道德經》是空不空、不二的經〔行389–391〕。

**發展：** 師說《道德經》文字艱深（他說是西周時代的篆書），看的人少、看了也不懂〔行394–398〕；他把第五章（他稱「卷五」，經名「用（守）中」）全文寫上螢幕〔行398–405〕，逐句講：
- **天地不仁，以萬物為芻狗：** 「仁」字從人從二——人具陰陽、好壞、善惡、佛魔二性〔行411–413〕；「天地不仁」不是天地沒有仁慈，而是天地不理會、不干預世間一切事——戰爭、災難時，天宮會怎麼樣嗎？不會〔行413–417〕。凡夫卻喜歡天地來干預：磕頭、布施、做紅龜粿、買鮮花，心裡說「請某某神明幫我度過難關」〔行417–419〕。師問大眾：十次祈求裡有幾次順意？「如果十樣只有一樣的話，是機率的問題」；不靈就去別家、加重供品，束縛越來越大，人生被你認定的神綁住〔行421–427〕。芻狗是稻草編成的祭品（《論語》孔子時代就有），供前珍惜、供後丟棄；天地把萬物當芻狗——不是看不起，而是「我不理會你、不干涉你」，萬物只是緣起緣滅〔行429–437〕。
- **聖人不仁，以百姓為芻狗：** 以天地之心為己心者叫聖人，也不干預人間的戰爭、災難、股票、景氣——因為世間的好壞是非善惡只是世間人緣起緣滅的感覺〔行437–441〕。師舉例：人活著時全家愛你，死了以後會把屍體放在旁邊天天陪嗎？七七四十九天一到「終於圓滿了，可以看電影了」——這就是眾生的心態，緣起珍貴、緣滅放棄〔行441–447〕。天地為何不理會？「你怎麼可以去干預人家的因果呢？因果自負。」〔行447–449〕拿三柱香去跟天地稟告私心，祂若干預就不是天地、更不是聖人，而且干預必須付出代價〔行451–453〕。「你聽老子的第一句話，你才不會步入迷信」——這是破迷信的第一關〔行455–459〕。
- **天地之間，其猶橐籥乎：** 孔子七歲拜為師的項橐，那個「橐」字；橐＝風箱，籥＝管子。天地像無限大的風箱，管子一通風就越膨脹〔行461–467〕。
- **虛而不屈，踵（動）而愈出：** 虛如虛空；「屈」在帛書古文作「掘」，意為取之不盡、用之不竭〔行467–471〕；越動它，能量越大、越活潑〔行473〕。「其實老子形容天地，就是我們的心」——六祖「何期自性本自具足」，心有無礙的本質，能生萬法；一念不覺生三細，心越動森羅萬象越精彩，由心所現、由識所變——這就是《妄盡還源觀》的自性清淨圓明體與「海印森羅常住用、法界圓明自在用」〔行473–483〕。「如果有人跟我講老子就是文殊再來，我都相信」〔行483〕。
- **多聞數窮，不若用（守）中：** 這多聞不是阿難的多聞（帛書作「多言」），是想太多、妄想執著太多，自性功德越被掩蓋，越來越窮〔行485–489〕；「中」＝回歸自性、進入不二、進入本心——觀世音「返聞聞自性，性成無上道」，人家叫你返聞，你卻往外多聞〔行489–493〕。

**要點：** 師稱魏晉南北朝郭象等人自言沒有老子這位先賢指引，佛法的自性功德不可能存在中國〔行493–495〕；大乘傳到東南亞、斯里蘭卡、西方都不興，唯中國能弘揚〔行495–499〕。佛教據考證於西漢哀帝元壽元年（西元前二年，近耶穌基督出生年代）傳入，老子則是西周末期人，孔子問禮於老子〔行501–503〕。「前無古人，可是後有來者」——佛經解釋得更圓滿〔行503–505〕。懂了這章，人生走得安穩，對宗教看得清楚：「原來一切天地就是在吾人的心中」〔行505–507〕。
- 出處：《道德經》第五章（先秦典籍，非 CBETA，見§6、§9 ※）。

### 4.3 二比丘犯婬殺——優波離螢光增罪結，維摩頓除如赫日銷霜雪〔行228–240〕

**設定：** 師說許多人的苦行是我們做不到的：一天一餐、每天三點起來拜佛、甚至甘願用火燒身，臨終卻覺得無望、期待下輩子再行菩薩道——因為沒有辦法安住本心〔行228–230〕。你的苦行勝得過頭陀第一的迦葉嗎？可迦葉在《維摩詰經》裡，維摩才真正告訴他苦行的涵義〔行230–232〕。

**發展：** 你的持戒比得過持戒第一的優波離嗎？有二比丘犯了婬、殺重罪，去找優波離；優波離講的方法「就好像螢火蟲的光一樣」，讓兩位比丘增罪結——本來罪就很大，聽完更大：「我沒希望了，只有地獄一條。」好在碰到維摩詰居士，「頓除疑，猶如赫日銷霜雪」〔行232–234〕。

**要點：** 「你罪再大也是假的，你福報再大也是假的」；罪跟福都是假，只要悟無生，本心功德顯現無遺，不被二元的罪福束縛〔行234–236〕。師並自嘲是「囉嗦的凡夫僧」，每週囉嗦，藉此把累劫的結慢慢打開，自利利他〔行238–240〕。
- 出處：《永嘉證道歌》T2014「有二比丘犯婬殺……猶如赫日銷霜雪」✓；〈弟子品〉T0475「時二比丘疑悔即除」✓（見§9）。

### 4.4 波斯匿王怕死——你有一個不死的自性〔行636–648〕

**設定：** 講到破「死魔」，師自述從小就很怕死，更怕爸爸媽媽死——自己還年輕，爸媽年紀大，最照顧我的人死怎麼會不痛苦〔行636–640〕。念大學時同學請假，因為祖父母死；出社會後，收到的訃聞是同學的爸媽；到了現在這個年紀，是同學、同事自己死了——死一直是眾生的陰影〔行640–642〕。

**發展：** 有一招：我有一個不生不滅的自性；這個身體一定會死（不死才奇怪），死是假的，真的不會死〔行644〕。師述：波斯匿王也很怕死，六十歲時跟佛陀說「我跟你同歲……我很怕死」；佛說你不會死，因為你有一個 Amrta（甘露、不死），就在你的自性；波斯匿王回去高興得不得了〔行646–648〕。

**要點：** 用不生不滅的自性破死魔——「死是影子在死，我真的也不會死」〔行652〕。
- 出處：《楞嚴經》卷二 波斯匿王觀河見性 T0945 ✓；經中王自言「今年六十二」，佛示「見精性未曾皺……彼不變者元無生滅」；「六十歲」「同歲」「Amrta」為師之轉述（見§9、§12）。

### 4.5 給孤獨長者與祇陀太子——奉諸所安〔行724–730〕

講到經文「奉諸所安」，師解為讓講這部經的人能安奉住所、安住道場來講經；就像給孤獨長者與祇陀太子供養那塊地（祇樹給孤獨園），讓佛陀講般若部，是同樣的道理〔行724–730〕。
- 出處：師述（祇園因緣為佛教通說）。

### 4.6 師之日常譬說（短敘）

- **刻名字的大功德主：** 捐一千萬、名字刻在那邊，出家在家把你視為上賓、請上座、入內壇——你的福報就被大家的讚賞領走了。中國人講「陰德」，布施不欲人知，最起碼保住福報；「人不知天知地知就好了」〔行349–359〕。師並以川普出去得到殊榮作比——有大家的擁護，與捐錢得擁護一樣〔行359–361〕。
- **狗沒有健保：** 一家人會吵架，唯獨對家裡的狗不吵；人看病捨不得自費，狗一律無健保什麼都好；投胎熊貓太有福報，投胎一般的熊跟貓就不好說——「物以稀為貴，這叫世間法」，六道之中千差萬別都只是相上的差別〔行270–278〕。
- **有福報的鬼叫神：** 迎神賽會時王爺、千歲多威風，沒有福報就當餓鬼〔行276–278〕。
- **商周殺人祭神：** 商以前殺人祭神是大福報，現在殺人祭神會被抓去關——世間罪福是世間人訂立的，都是假的〔行262–264〕。
- **還債與勞動服務：** 沒錢還債，就用熱心公益、利益眾生來還；刑法也有不用坐牢、改勞動服務的——「本來人生就是以服務為目的」（國父語）〔行570–580〕。

## 8. 本經解義（《維摩詰所說經》T0475〈法供養品〉逐段）

> 本講上螢幕並讀出的經文，依經文段序列為三段全文（自然句起訖、無中間省略），再逐句列體佛法師釋義。第三段讀至「十方三世諸佛所說」，師即說「好先到這邊」〔行839〕；其後「若聞如是等經……」本講未讀。

**段一：釋提桓因白佛（作證並發護法願）** ✓ CBETA T0475〔行284–293〕
> 爾時釋提桓因於大眾中白佛言：「世尊！我雖從佛及文殊師利聞百千經，未曾聞此不可思議、自在神通、決定實相經典。如我解佛所說義趣，若有眾生聞是經法，信解、受持、讀誦之者，必得是法不疑，何況如說修行？斯人即為閉眾惡趣開諸善門，常為諸佛之所護念；降伏外學，摧滅魔怨；修治菩提，安處道場；履踐如來所行之跡。世尊！若有受持讀誦、如說修行者，我當與諸眷屬供養給事；所在聚落城邑、山林曠野有是經處，我亦與諸眷屬聽受法故，共到其所；其未信者，當令生信，其已信者，當為作護。」

**段二：佛讚天帝，並校量法供養功德** ✓ CBETA T0475〔行293–307〕
> 佛言：「善哉，善哉！天帝！如汝所說，吾助爾喜。此經廣說過去、未來、現在諸佛不可思議阿耨多羅三藐三菩提。是故，天帝！若善男子、善女人受持、讀誦、供養是經者，即為供養去、來、今佛。天帝！正使三千大千世界如來滿中，譬如甘蔗、竹□、稻麻、叢林；若有善男子、善女人，或一劫、或減一劫，恭敬尊重，讚歎供養，奉諸所安，至諸佛滅後，以一一全身舍利起七寶塔——縱廣一四天下，高至梵天，表剎莊嚴——以一切華香、瓔珞、幢幡、伎樂微妙第一，若一劫、若減一劫，而供養之，於天帝意云何，其人植福寧為多不？」釋提桓因言：「多矣！世尊！彼之福德，若以百千億劫說不能盡。」佛告天帝：「當知是善男子、善女人聞是不可思議解脫經典，信解受持，讀誦修行，福多於彼。所以者何？諸佛菩提皆從是生；菩提之相不可限量，以是因緣福不可量。」

（CBETA 底本「竹□」缺字，師讀作「竹葦」〔行299〕〔行716〕。）

### 義理深入（依維摩本品之框架）

**（一）天帝作證「決定實相經典」——〈法供養品〉先為全經定性。** 釋提桓因隨佛與文殊聞百千經（含般若部），卻說「未曾聞此不可思議、自在神通、決定實相經典」〔行317–323〕。體佛法師扣住兩個詞：「決定」取《證道歌》「決定說表真乘……直截根源佛所印」，摘葉尋枝的方便法不是決定說，直截根源所印的就是我們的心〔行325–329〕；所以天台大師、永嘉大師都因此經成就，禪宗祖師的偈語也出自此經〔行331–333〕。「實相」則是無相·無不相·無相無不相，配空·不空·空不空如來藏〔行337–341〕。這一定性決定了整品的讀法：流通分要流通的不是一部「功德經」，而是「心的說」——所以後面的校量功德，比的是「事相的財供養」與「回歸本心的法供養」。

**（二）校量功德——法供養之所以勝，在「諸佛菩提皆從是生」。** 經文先把財供養推到極致：三千大千世界如來滿中、一劫恭敬供養、滅後全身舍利各起七寶塔縱廣一四天下高至梵天，天帝答「百千億劫說不能盡」〔行712–742〕。而聞此經信解受持讀誦修行者「福多於彼」，理由只有一句：諸佛菩提皆從是生〔行769–773〕。師以《金剛經》「諸佛皆從此經出」對照，並把「菩提之相不可限量」直指為「本自具足的這個心」〔行777–795〕；再以文殊靜坐偈「寶塔畢竟化為塵，一念淨心成正覺」作同義印證——寶塔是生滅法，一念淨心是當下回歸本心〔行759–767〕。所以法供養的「法」不是另一種供品，而是令供養者與受供者同歸本心；這是〈法供養品〉校量的真正判準。

**（三）藥王本事——月蓋的一念「寧有供養殊過此者」就是轉凡入聖的關口。** 寶蓋與千子十劫財供養，是凡夫在「有」上做到極致；月蓋獨坐思惟一問，空中有天應之〔行873–877〕。師的開解把佛答「法供養者，諸佛所說深經」整段讀成如來藏的三分：深經難信難受、清淨無染、非分別思惟能得——是空如來藏〔行879–903〕；陀羅尼印＝《楞伽》空·無生·不二·無自性相〔行905–909〕；成就六度＝以空如來藏行不空如來藏〔行909–917〕；入大慈悲＝菩提心三心，大悲心是不空如來藏的緣起〔行921–927〕；順因緣法無我無人＝破四相入空〔行931〕；坐道場轉法輪＝從空入不空〔行933–935〕。依師的讀法，〈法供養品〉並非全經的附錄，「它是真正把空如來藏、不空如來藏講得很清楚的最後一段」〔行935〕。

**（四）以《道德經》與《楞嚴經》雙證「決定實相」，並落實為「不介入因果」的生活觀。** 本講在經文之間插入兩大開展：《道德經》第五章與《楞嚴經》「性色真空」〔行394–608〕。兩者對照：老子「天地之間其猶橐籥乎，虛而不屈，動而愈出」＝《楞嚴》「如來藏中性色真空、性空真色，清淨本然，周遍法界」（如來藏的自然狀況）〔行548–550〕；老子「天地不仁」＝如來藏「隨眾生心，應所知量，循業發現」而不干預妙有的生滅（天地無私）〔行560–562〕；老子「多聞數窮，不若用中」＝《楞嚴》「世間無知，惑為因緣及自然性……但有言說，都無實義」，凡夫執有、聲聞執空皆是識心，回歸不二才是中〔行588–608〕。由此落到生活：佛菩薩不介入因果，該還就還，心安即消業障〔行562–580〕；災難是本心菩薩的示現，以感恩代替抱怨〔行200–206〕。這正是持經者「降伏外學，摧滅魔怨」的根柢——不再向外求神干預，而是回歸本心。

## 11. 日常實踐

1. **三字訣「不執著」：** 動不動生氣、不滿、抱怨，就是著相；在相中不執著，即隨流認得性。〔行56–58〕
2. **觀「想」：** 想起喜歡或討厭的人時，提醒自己：這個人是我心想出來的，情緒也是假的。〔行62–72〕
3. **轉台：** 心隨萬境轉，連按都不要——當下轉念即是一念三千。〔行138–140〕
4. **嗔起時觀其無生：** 不忍耐、不壓抑，觀嗔如空谷響、旋火輪，因緣生當下即可滅。〔行128–136〕
5. **以幻取幻：** 念佛、持咒、聽經都是以假修真，目的是回歸真心。〔行210–214〕
6. **災難中感恩：** 災難是本心菩薩的示現，考驗也是假的，如看一場電影。〔行200–206〕
7. **布施不欲人知：** 尚在人天乘時，最好的方法是布施不欲人知（陰德）；進一步學三輪體空。〔行355–363〕
8. **不求神干預：** 天地不仁、佛菩薩不介入因果；拜拜只是讓自己心安，真正要做的是回歸本心。〔行451–459〕〔行566–570〕
9. **該還就還：** 業障來了不要逃避，沒錢就用熱心公益、利益眾生來還，心安即消業障。〔行566–578〕
10. **少想多返聞：** 多聞（妄想）數窮，不若用中——往內返聞，不往外多聞。〔行485–493〕
11. **讀通不只讀誦：** 信、解、受持（用在日常生活）、讀通、如說修行。〔行612–620〕
12. **時時警覺：** 一被幻相干擾就警惕回本心——這才是真正持戒。〔行242〕
13. **看人看本心：** 每說一聲「阿彌陀佛」，是看到對方本心的自性。〔行244–246〕
14. **建道場只為隨緣：** 有緣即講，無緣即止；不為名聲、不為事業。〔行941–947〕

## 12. 延伸・參

**相關講次：** 第60講（《楞嚴經》性色真空性空真色，本講補足）〔行335〕〔行509〕；下講續〈法供養品〉「若聞如是等經……是名法之供養」、月蓋比丘本生與〈囑累品〉〔行841–843〕。

**師述與經典出處之更正（詳見 校對）：**
- 「返聞聞自性，性成無上道」師歸於「觀世音菩薩《念佛圓通章》」〔行491〕——此句出《楞嚴經》卷六文殊菩薩選圓通偈，讚觀世音**耳根圓通**；「念佛圓通章」是大勢至菩薩章（T0945）。
- 「若人靜坐一須臾」偈，師稱「取自於《華嚴經》的文殊菩薩偈頌」〔行756〕——根本《華嚴經》T0279 無此偈；見《廣清涼傳》T2099（宋·延一編），為文殊化身老人為無著所說；《真心直說》T2019A 引作「古頌」。
- 「佛在講五教……小始終頓圓」〔行110–112〕——五教（小乘、大乘始、終、頓、圓）是賢首法藏《華嚴一乘教義分齊章》所立之判教（T1866），非佛說。
- 波斯匿王「60歲……我跟你同歲」〔行646〕——《楞嚴經》卷二王自言「今年六十二」；經中無「同歲」語，「Amrta（甘露·不死）」是師對「見精性……元無生滅」之詮釋。
- 「平常心是道場」〔行656〕——〈菩薩品〉作「直心是道場」（T0475）；「平常心是道」為禪門語。

- 師稱《道德經》為「西周時代的篆書」、老子「三千年前」〔行396〕〔行493〕；老子年代學界多定於春秋。
- 師稱郭象等自言無老子則佛法自性功德不存中國〔行495〕；郭象為西晉人，此說出處待查。
- 佛教傳入「西漢哀帝元壽元年」〔行501〕為伊存授經說，屬傳入諸說之一。
- 「三祖、五祖引用的偈語都是用《維摩詰所說經》」〔行333〕、「第十二品五祖認為很重要」〔行126〕——出處待查。
- 師述「七佛滅罪真言」之七佛＝莊嚴劫三佛＋賢劫四佛〔行863–865〕，與《景德傳燈錄》七佛列次相合，可另查真言出處。
