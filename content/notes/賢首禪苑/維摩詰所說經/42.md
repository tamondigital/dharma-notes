## 1. 本講概要

本講續講〈入不二法門品〉，三小時只講兩位菩薩——**無盡意菩薩**（布施與迴向一切智不二）與**深慧菩薩**（空、無相、無作三解脫門，「於一解脫門即是三解脫門」）。法師自己說「三個小時講兩位菩薩，越講越少」，但「這個不是時間性的關係」〔行880-882〕。

全講的貫串線是：**「二」是世間法（相對待），「不二」就是本心，本來不二、不是修來的**〔行13-28〕。煩惱、輪迴都只是「被這個二所干擾」，而干擾者是自己〔行28-32〕。

全講分四大段：

1. **開場——入不二＝回歸本心**：六根六塵六識，六塵是幻（《涅槃經》六大賊）；自利利他＝菩薩；薰習的重要〔行11-80〕。
2. **恭迎佛陀法身舍利，講釋迦牟尼佛傳給迦葉的偈**「法本法無法，無法法亦法，今付無法時，法法何曾法」（二十字中十字是「法」），並連到七佛、禪宗法脈、拈花微笑、永嘉「心是根，法是塵」〔行82-168〕。
3. **無盡意菩薩**：布施的當下就是迴向；以《金剛經》無住布施、〈普賢行願品〉十大願、華嚴十信→十迴向（佛膝放光表法）、大珠慧海《頓悟入道要門論》（引《思益經》）六度六法、清涼國師《華嚴經疏》十種迴向／三處迴向，層層詮釋「布施性即是迴向一切智性」〔行170-458〕。
4. **深慧菩薩**：三解脫門（三門非山門）；以《文殊師利所說不思議佛境界經》、《大智度論》（狂慧／生死坑、城有三門）、《大品般若》、支謙《大明度經》（含月氏／貴霜史、支謙生平）、支謙《佛說老女人經》（木火・鼓・畫三喻悟無生）會通；最後以**真言宗五方五佛・轉識成智**解「若空、無相、無作，則無心、意、識」〔行460-880〕。

## 4. 故事・公案（全敘）

### 4.1 影子日記（為什麼被六塵欺負是荒謬的）〔行56-60〕
法師說：你今天出去看到你的影子，我不相信你那天寫日記會寫「影子日記」——「唉呦，我的影子變瘦了」「我的影子變胖了」「突然間沒看到我的影子」「我的影子變矮了，那一天我心情很不好，為了我的影子而傷心痛苦」。如果真有人這樣，「先不要來聽經，先去看精神科」——因為已經絕對誤解了。既然你知道這不可能，為什麼日常生活中會被六塵欺負而痛苦？要這樣善思惟，推到有一天不再被影塵欺負，就不只開悟，而是進入佛法身的徹悟。〔行56-60〕

### 4.2 恭迎佛陀法身舍利・七佛〔行82-96〕
本講當天禪苑恭迎佛陀法身舍利，所以法師以佛陀的偈語開端。先講七佛滅罪真言的七佛：上一劫莊嚴劫的最後三佛——毘婆尸佛、尸棄佛、毘舍浮佛（毘舍浮佛偈「假借四大以為身」至今仍是開悟偈語）；本劫賢劫的四佛——拘留孫佛、拘那含牟尼佛、（法師此處說「燃燈佛」，見 §5 校正）、釋迦牟尼佛。〔行82-88〕佛陀的身骨舍利讓我們紀念，看到它就看到戒定慧、法化報三身；但佛除了有形舍利，還傳無形的法義——就是這首偈。〔行94-96〕

### 4.3 拈花微笑・付法迦葉〔行99-105〕
法師敘述：大梵天王（逐字稿作「大自在天」）獻金色花，佛陀拈花，迦葉尊者微笑；佛說「我有一個正法眼藏、涅槃妙心、微妙正法、實相無相、不立文字、教外別傳，傳給你迦葉」，迦葉首傳燈。佛陀實際說出的文字就是那首偈；迦葉從一個聲聞大阿羅漢，當下成為大乘法身大士。〔行101-105〕（傳燈錄 T2076 原文作「吾以清淨法眼涅槃妙心實相無相微妙正法將付於汝」，見 §9；「不立文字、教外別傳」與金色花之說見於後出禪籍，※ 不在 T 藏此處。）

### 4.4 〈弟子品〉十大弟子中唯一「講話」的迦葉〔行105-111〕
法師說：〈弟子品〉中維摩詰一一糾正佛的十大弟子，其中九位都沒講話——還沒真正參到；唯有一位跪著說「我知道了，就是這回事」，以後又再出現講一次，這位就是年紀最大的頭陀尊者迦葉，從這偈語悟成法身大士。〔行107-111〕（經中迦葉白佛：「聞說是語，得未曾有，即於一切菩薩深起敬心」，後於〈不思議品〉又歎「一切聲聞聞是不可思議解脫法門，皆應號泣」，✓ T0475。）

### 4.5 佛陀「好囉嗦」——苦口婆心〔行210-218〕
法師自述剛學佛時沒什麼悟處，覺得佛陀好囉嗦：「東方虛空可思量不」講完，又講南西北方、四維上下，「東方西方不是一樣嗎？」後來越體悟越知道佛陀大慈大悲、一再叮嚀，「沒有人願意這麼囉嗦，祂真的是苦口婆心」。所以「以後度眾一定要苦口婆心，不怕艱辛、不怕煩擾、不怕囉嗦，該講的一定要講到底」。〔行212-218〕

### 4.6 富樓那掉淚（真懺悔業障）〔行247-251〕
法師講懺悔業障：懺悔的不是「我昨天做了什麼事」，而是累劫的「有為陋習」。他引《楞嚴經》：佛告富樓那「你已經得到如來的妙空法要了，怎麼這些有為的陋習還會再困住你呢」，富樓那就掉了眼淚。輪迴是一場誤會，被那個陋習綁到現在。〔行247-251〕（※ 經文主客相反：T0945 是富樓那問佛「如來今得妙空明覺，山河大地有為習漏何當復生？」見 §5、§9.3。）

### 4.7 賢首國師・武則天・鏡中佛像・開經偈〔行269-293〕
法師講華嚴十信位的座主是賢首菩薩。唐朝法藏比丘（華嚴三祖），武則天認為他是華嚴會上賢首菩薩化身，因賢首菩薩負責讓眾生進入信位——「信為一切道源功德本」，信沒有進去後面都不必談。〔行269-275〕武則天對事事無礙、重重法界怎麼想都想不通，法藏立一尊佛像，四周上下安鏡子（像電梯四面鏡子看不到盡頭），請武則天進入鏡中——她看到佛像重重無盡，也看到她自己重重無盡地出現。法藏說：這就是心的作用、理事無礙、事事無礙的無盡法界。武則天當下大徹悟，以帝王之身向比丘三頂禮，稱他為國師，從此被稱賢首國師；禪苑之名「賢首」即讚歎此功德與《妄盡還源觀》。〔行277-287〕她脫口而出「無上甚深微妙法，百千萬劫難遭遇，我今見聞得受持，願解如來真實義」，從此成為所有大乘經典的開經偈。〔行287-289〕她一生雖有很多罪行（包括害死王皇后），但法師引蓮池大師《竹窗隨筆》：真正能消武則天業障的不是水陸法會，而是這智慧之語——後世只要有人還念這偈，她就分享著眾生的功德。反之，毀謗佛法、斷人慧命，罪惡也重重無盡。〔行289-295〕
（※ 核驗：《宋高僧傳》T2061 載法藏「字賢首」，為則天講新《華嚴》時用的是「鎮殿金獅子」為喻（《金師子章》），十面鏡中安佛像燃炬，是「為學不了者設巧便」；開經偈出武則天、竹窗隨筆之說不在 T 藏，標未驗。見 §5、§9.3。）

### 4.8 佛陀講十迴向，膝蓋放光（表法）〔行301-313〕
《華嚴經》記載佛陀講十迴向位時，膝蓋發光。法師解：膝蓋是承接一個人上下的關節，壞了就不能走路；十迴向承十信、十住、十行，啟十地乃至成佛，所以用膝蓋表法。「佛經寫出來是沒有解釋而已，一定有它的用意……為什麼不鼻子、不頭部、不肚臍發光，偏偏是膝蓋？」〔行301-307〕

### 4.9 歌利王割截身體（忍辱）〔行336-342, 356-358〕
佛陀憶起過去被歌利王割截身體，為什麼不生氣、不瞋恨？因為無我相、無人相、無眾生相、無壽者相。法師並說：因這一件公案的功德，本來彌勒菩薩要成為賢劫第四尊佛，釋迦牟尼佛就變成第四尊，彌勒變成第五尊。〔行338-340〕（彌勒、釋迦次第之說未在本講所引經文中驗到，※ 標法師所述。）

### 4.10 奧林匹克考驗〔行354-358〕
人生中歷經一次「作夢也想不到」的挫折——「你是修行人，我就要恭喜你了，題目來了」，像奧林匹克運動會練習多年終於要比賽，「請你們好好表現吧，才不辱於佛陀」。修行一定要考驗；只要經驗一次「沒有忍可忍」，第二次、第三次就可安然度過，安住本心＝十住位。〔行350-358〕

### 4.11 清涼國師之名・宗密〔行386-393〕
澄觀大師入宮，所講每句話皇帝都說「我心已清涼矣」，因此被稱清涼國師。宗密沒見過澄觀，讀他的《華嚴疏鈔》而大徹大悟；宗密是《圓覺經》專家，承禪宗神會與華嚴兩脈，影響永明延壽乃至宋明理學。〔行389-393〕（※ 清涼名號由來未在 T 藏驗到此語。）

### 4.12 月氏與貴霜王朝・張騫・支謙〔行534-587〕
法師以地圖講：月氏本居甘肅，被匈奴打擊分兩派，一派遷祁連山稱小月氏，一派西遷至中亞，又被烏孫打擊再遷至印度西北（今喀什米爾一帶），自稱大月氏，建貴霜王朝（法師列印度三大王朝：孔雀、笈多、貴霜），控制絲路交通、收關稅，大乘經典的翻譯與集結在其控制下完成；馬鳴菩薩被貴霜王朝請來，形成犍陀羅文化。〔行540-562〕張騫第一次通西域，目的是聯絡大月氏夾擊匈奴；貴霜帝王答「我已經不介入以前的仇恨了」——法師說「張騫也被人家上了一堂佛教課」，第一次失敗，回程又被匈奴俘虜。〔行542-560〕支謙是大月氏後裔、優婆塞（在家人），三國時在吳翻譯；當時中國瀰漫道家儒家，他以道家最高境界「無極」翻譯，故名《大明度無極經》：大＝摩訶，明＝本心寂滅不二產生的大明，度＝度化，無極＝圓滿自性。孫權看重這位外族在家人，請到建業（今南京）奉為國師，讓他安心譯經。〔行562-576〕鳩摩羅什（姚秦）晚支謙近百年，羅什說他翻《維摩詰經》很重要的依據是支謙本；孫權看《維摩詰經》跳起來說「來自天竺的世尊這麼偉大，不下於我們中國的老子」。〔行578-587〕

### 4.13 《佛說老女人經》——百歲老女人悟無生（全敘）〔行589-727〕
法師說這是支謙所譯、明朝以後幾乎失傳的經，「我迫不及待要介紹給各位，這太感人了」。〔行589-597, 718〕

- **緣起**：佛講經說法時，有一位一百多歲、生活困苦、滿面愁容、駝背、衣服破了又補的貧窮老女人，慢慢走進僧團；侍者弟子沒有阻擋，因為看佛陀的眼神好像準備迎接她。她跪在佛前，自稱「老女人」（經名由此而來；「老」是尊敬，如「大老」），訴苦說活到一百多歲、兒女都死了、孤苦伶仃。〔行597-605, 626-630〕
- **四類問題**：生從何來、去至何處？老、病、死從何來去？地水火風四大從何來去？五蘊從何來去？六根從何來去？——佛還沒答，她一連串問完。〔行605-620〕
- **第一喻・木與火**：佛不正面回答，舉木中生火、木盡火滅，問她火從何來、去至何所。她答：火要有條件，因緣合便得火、因緣離散火便滅。佛說：「你問的問題，從此類推」——無所從來，亦無所從去。老女人第一次掉淚。〔行630-672〕
- **第二喻・鼓**：只有鼓面、只有鼓檯、只有鼓槌，會發聲嗎？不會；鼓槌往鼓面一敲，聲音就出來了——聲音從因緣而來、因緣滅而滅。老女人第二次掉淚。〔行672-680〕
- **第三喻・畫**：要有畫面（當時應非紙——蔡倫造紙在東漢和帝，晚佛陀近千年）、顏料、筆，加上作畫人；畫從因緣所生而來，因緣離去而離。所以無自性性，稱為空，本無生。老女人第三度掉淚，佛印證她得正法眼（法師說入初住的大菩薩）。〔行680-690〕
- **阿難問・前世因緣**：阿難問佛：這老女人怎麼這麼有智慧？佛說：如果她跟我沒關係，我講這番話她不會聽。在賢劫第一尊佛拘留孫佛時，老女人是我的母親；我聽聞拘留孫佛法要想出家，母親為母女之情嚴格禁止、限制我的行動，我困苦悲傷失意。因此她感得五百世貧窮困苦、且年紀都很大。「不能限制一個菩薩想利益眾生，你限制他的後果是如此」；但因緣不變，她一百多歲終於找到我，我能打開她這個結。老女人激動得「簡直想抱著佛陀，只是沒有喊一聲女兒」。〔行690-710〕
- **授記**：佛說她以後一定成佛，號波犍如來，國名化華；隨她投生的眾生壽命一劫，無貧苦，生活如忉利天，並受薰陶必定成佛。〔行710-718〕
- **法師結語**：所謂悟無生就是這個道理。說不定你在哪一劫是佛陀的兒子、兄弟姐妹，今天聽到這經才會毫不退縮地聆聽。〔行718-727〕

（✓ 經文核驗：T0559 全經存。佛答之全文、三喻（經中實有木火、鼓、雲雨、畫師四喻）、「是我前世發意學道時母也」「往昔拘留秦佛時，我欲作沙門。是母慈愛，不肯聽我去」「五百世來生世間輒貧窮」「號波犍，其國名化華」皆見 §9。※ 「一百多歲」「三度掉淚」「佛為女兒」「凸透鏡」等細節為法師敘述，經中未見；經中另有「今壽盡當生阿彌陀佛國」「却後六十八億劫當作佛」，法師未提。）

### 義理深入（依次）

**無盡意菩薩——「布施的當下就是迴向」（〔行177-458〕）。** 法師先拆掉兩個世俗誤解：其一，布施不是單向的施恩——布施是對待性的，「你布施給人，等於他布施給你」，連乞丐都在讓你種福報；得了名聲、掌聲，就是已經拿到回報，「還要去還人家」〔行180-194〕。其二，迴向不是事後再加一道儀式——「你還心裡面想說再幫我迴向一下，這迴向已經沒有功德了」，因為那是有所求、仍在二元世界〔行198-202〕。正見是：迴向一切智＝迴向本心，**布施的當下就是迴向，條件是無所住**——這正是《金剛經》「應無所住行於布施」，其福德如十方虛空不可思量；反之住相布施只是生天福，如仰箭射虛空〔行202-220〕。接著法師用四重經論把「迴向」講透：①〈普賢行願品〉十大願最後普皆迴向，迴向的是一切智的本心，「虛空有盡，我願無窮」〔行220-267〕；②華嚴行位，十迴向承先啟後，十迴向位的見地是「修一切功德而無功德可得，度一切眾生而無眾生可度」，所以佛講十迴向時膝蓋放光〔行295-313〕；③大珠慧海《頓悟入道要門論》引《思益經》：六度即捨、無起、無念、離相、無住、無戲論，「但修檀之法，即萬法周圓」——布施為首，一則涵蓋六，而前五度須般若之眼帶領，般若就是迴向一切智〔行317-380〕；④清涼國師「迴者轉也」，十種迴向從迴自向他一路到「迴隨順理事向理所成事」（事事無礙），總歸三處：實際（真際）、菩提、眾生〔行382-429〕。四重歸一：**六度是相、迴向一切智是性，性相一如，於其中入一相（平等）即入不二**〔行432-458〕。

**深慧菩薩——三解脫門與「則無心、意、識」（〔行460-880〕）。** 法師先正名：三門不是山門，空門居中、無相門無作門在兩旁，三解脫門亦名三三昧、三三摩地，無作亦稱無願〔行468-474, 729〕。再以三部經論層層證成：《文殊師利所說不思議佛境界經》佛答文殊「我於空境界得菩提，諸見平等故」，佛在空、無相、無作中、在一切有為法中見平等而得菩提——法師說此與《金剛經》「若見諸相非相即見如來」幾乎同義，又回扣《楞伽》「空、無生、無二、離自性相」〔行474-510〕；《大智度論》則警告三種智慧若不住定中即狂慧、禪定中無此三法則還墮生死——定慧等持才是真三解脫門〔行510-530〕；三解脫門最早的漢譯是支謙《大明度經》，由此帶出支謙其人與其所譯《老女人經》的「悟無生」——因緣和合而生、因緣離散而滅，即無自性性、即空〔行532-727〕。經文本身的論理是「A＝B＝C」：空即無相、無相即無作，一門入即三門入〔行731-742〕。最難的是「若空、無相、無作，則無心、意、識」：法師用真言宗五方五佛說明，凡夫就是法界體性智一念不覺而現八識、在東西南北中循環輪迴；入三解脫門，八識當下轉為四智，自心五佛顯現——所以「於一解脫門即是三解脫門」就是回本心、入不二法門〔行744-880〕。

連結要點：法師說「十種總歸三種：迴向真際（實際、法界、實相）、迴向菩提（本心）、迴向眾生」〔行425-429〕，最後一種＝從理事無礙入事事無礙，「這是華嚴的最終境界」〔行413-423〕。（法師列次與疏文略異，名稱「迴小向大」「迴此向證」為其口述形；疏作「迴比向證」。）

華嚴四法界（法師〔行413-423〕）：

```
事法界 → 理法界 → 理事無礙法界 → 事事無礙法界
                     （隨順理事）      （理本成事＝相即相入：在相中當下見法界）
```

```
阿賴耶（八）──因緣成熟去投胎──▶ 前五識（一到五）──▶ 第六意識（分別）──▶ 第七末那（我執）
     ▲                                                                       │
     └──────────────── 把這輩子真妄一切收回阿賴耶 ◀────────────────────────┘
```

連結要點：深慧菩薩「若空、無相、無作，則無心、意、識」＝**入三解脫門，心（八）、意（七）、識（六・前五）當下轉為四智，自心五佛顯現**——「眾生本具的五佛」〔行838-853, 876-880〕。所以念佛名號、持咒，要懂這道理，透過三密相應轉阿賴耶、我執、分別、五識執著的習性〔行855-859〕；《起信論》「一念不覺生三細」是凡夫一側的來源〔行760-762〕。

## 11. 日常實踐（可操作）

1. **影子檢驗**：遇到讓你痛苦的人事物，問自己「這是不是在寫影子日記？」——六塵是幻，放下＝它干擾不了你，不是放棄〔行56-64〕。
2. **布施當下就迴向**：不必事後「請師父迴向一下」；布施時不求回報、不求名、也不執著「不需要」，「對方想怎麼樣，隨便他」〔行194-206〕。
3. **把一句謝謝當布施**：日常六度——說謝謝、幫家人做早餐（布施）、守規矩（持戒）、遇不如意（忍辱）、過程（精進）、心中定性（禪定），以「一切是幻相、本心不礙」的智慧帶領（般若）〔行448-458〕。
4. **忍辱＝無忍可忍**：不是咬牙忍耐（忍耐會爆發），是知道「沒有辱讓你忍」；經驗過一次，第二、第三次就安然度過〔行342-354〕。
5. **持戒不起持戒狂**：持戒是回本心（清涼），不是用來輕蔑他人〔行334, 368, 374-376〕。
6. **背誦傳法偈**：「法本法無法，無法法亦法，今付無法時，法法何曾法」——煩悶時、找不到方向時、臨終時想起它〔行161-168〕。
7. **自我評量修行**：不必問師父「我開悟了沒有」——看自己是否一天比一天煩惱更少、更活潑、更自在〔行257-261〕。
8. **薰習不斷**：每週聽經如染香人；正法薰習到「三界與泥犁越來越遠」〔行74-80, 882-884〕。
9. **觀相即法界**：看到任何相，不加思考、當下知其虛妄、即是法界——事事無礙的練習〔行417-423〕。
10. **轉識練習**：察覺取捨（第七我執）→觀其平等（寶生）；察覺分別（第六）→觀其如幻（阿彌陀）；察覺著相收藏（第八）→如鏡不留（阿閦）；五根對五塵→善用成就事業而不受干擾（不空成就）〔行796-853〕。
